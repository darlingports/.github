# DarlingPorts

Native Linux launchers, runtime shims, and compatibility fixes for running macOS applications and games on Linux via [Darling](https://www.darlinghq.org/).

> [!NOTE]
> I only put darling stuff here that needs / is better with some kind of launcher, if that isn't needed it get put on the [Darling AppDB](https://appdb.darlinghq.org/).


## Projects

- **[Darblox](https://github.com/DarlingPorts/darblox)** — Native GTK4/libadwaita launcher and runtime compatibility shim for running the macOS Roblox client on Linux under Darling.
